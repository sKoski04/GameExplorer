# Game Explorer 🎮

### Game Explorer is a React-based content management system. I wanted to create this project to learn about content management systems and to create my own using React. This project is a mixture of different react components that display variety of content in different components. Some components are built by me and some are from react bootstrap.

<img width="1901" height="904" alt="image" src="https://github.com/user-attachments/assets/0c035973-45eb-455c-8ed6-06c869f791fc" />

## Goals for this project

* to learn the basics of content management systems.
* Learn to display content of many forms in suitable components (text, videos, images...).
* learn to create components and a whole website that fits the theme and content.
